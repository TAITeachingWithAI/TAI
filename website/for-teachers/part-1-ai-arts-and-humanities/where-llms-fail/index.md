# Where LLMs fail

Building on *How LLMs work*, students predict which tasks will be hard for a
language model, and then put their predictions to the test by challenging an LLM.
They check whether its answers are correct and whether it used external tools,
such as a web search or code. The lesson ends with conclusions on when to trust an
LLM and when to double-check.
