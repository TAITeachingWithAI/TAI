# Languages

Students use a language model as a personal tutor for a language they are
learning. After a short class discussion, they chat with an LLM in that language,
so that it can assess their level and what they still need to work on. The LLM
then gives them a personalised lesson, and the class closes with a discussion of
how useful AI is for learning a language.

## Lesson material

There is no separate teacher version of this lesson: teachers use the same material as the students.
