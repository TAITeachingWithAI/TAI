# Notebooks for the math lesson

The notebooks belonging to the mathematics lesson. Each one comes in two
versions:

- the **full version**, with the code already written out;
- the **AI version**, a stripped-down notebook where the code is meant to be
  produced together with an AI assistant.

Click **Open in Colab** to run a notebook in your browser without installing
anything, or download the `.ipynb` file to run it locally.
