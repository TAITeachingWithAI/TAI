## Data-analysis notebook

Students use this Colab notebook to load and analyse their light-sensor data: it
draws the light curve, computes the transit depth, and plots transit depth vs.
planet size². It accepts a CSV from Physics Toolbox, the Arduino Science Journal,
or any plain CSV.

Click **Open in Colab** to run it in the browser without installing anything, or
view and download it on GitHub.
